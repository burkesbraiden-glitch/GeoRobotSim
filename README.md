# GeoRobotSim

真实地理环境高真实感机器人仿真与验证平台。

## Project Goal

通过构建一个真实的机器人仿真与验证平台，系统学习：

- 真实地理环境建模
- 机器人运动与控制
- ROS 2
- TF 与坐标系统
- Camera / LiDAR / IMU
- Localization / SLAM
- Path Planning
- Robot Learning
- Sim2Real

## Current Stage

Week 1 - Development Foundation

当前目标：

建立开发环境、项目工程结构和基础状态模拟程序。

## Architecture

The project will gradually contain:

- Real geographic environment
- Unreal Engine / Cesium simulation
- Robot models and sensors
- ROS 2 communication
- Navigation and control
- Monitoring and experiment system
- Robot Learning / Sim2Real extensions

## Development Environment

### Windows Host

- Unreal Engine
- Cesium for Unreal
- High-fidelity rendering and simulation

### Ubuntu VM

- Linux development
- Python / C++
- ROS 2
- Robot algorithms
